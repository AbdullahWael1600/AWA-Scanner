# AWA Scanner

ماسح مستندات شخصي يعمل كصفحة ويب قابلة للتثبيت (PWA).

## التشغيل محليًا
- افتح المجلد في VS Code.
- شغّل الموقع عبر Live Server أو أي خادم محلي؛ لا تفتح `index.html` مباشرة إذا أردت اختبار Service Worker.

## النشر المجاني على GitHub Pages
1. أنشئ Repository جديدًا واجعله Private إذا كان متاحًا لحسابك وتريد تقليل ظهوره. تذكّر أن GitHub Pages للمستودعات الخاصة يعتمد على نوع الحساب/الخطة، لذلك قد تحتاج مستودعًا عامًا.
2. ارفع كل الملفات الموجودة في هذا المجلد إلى جذر المستودع: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`.
3. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/(root)` واحفظ.
4. افتح رابط Pages على الهاتف، ثم اختر Add to Home Screen / تثبيت التطبيق.

## OCR والخصوصية
- محرك Tesseract وبيانات اللغات تُحمّل عند أول استخدام OCR، لذلك يلزم الإنترنت أول مرة.
- الصور تتم معالجتها داخل المتصفح ولا يرفعها التطبيق إلى خادم AWA.
- يمكن اختيار عربي + English أو لغة واحدة أو أرقام فقط. خيار تحسين الدقة يجرب نسختين من المعالجة ويختار الأعلى في درجة ثقة Tesseract، لكنه أبطأ وليس ضمانًا لصحة كل رقم.
- Excel يحتوي سطر النص المستخرج ودرجة الثقة التقريبية لكل سطر. راجع الأرقام يدويًا قبل استخدامها في معاملات أو مستندات مهمة.

## ملاحظة عن Offline
Service Worker يخزن ملفات التطبيق الأساسية من نفس الموقع. مكتبات CDN وملفات لغة OCR الخارجية قد تحتاج اتصالًا عند أول استخدام، ولا نعد بأن OCR سيعمل دون إنترنت على كل جهاز حتى يتم اختبار التخزين المؤقت على الجهاز نفسه.
